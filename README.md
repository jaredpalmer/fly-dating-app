# WING

**Born to fly. Forced to date.**

A fictional, Hinge-like dating app for a connectome-driven fly. **166,700 neurons. 25.6 million connections. 36 eligible female flies.**

Francis browses profiles on his phone while an explicit decision policy turns measured dopamine-neuron activity into likes or passes. Watch the physical fly in its 3D observation chamber, read the same profile up close, and inspect the neural evidence behind each decision.

**Built directly on and inspired by [Fly / Wirehead by @mattyhempstead](https://github.com/mattyhempstead/fly-wirehead)**, the project that gave a fly-connectome simulation a phone and a feed of insect Shorts. WING inherits its local neural backend and observation chamber, and replaces the scrolling feed with a fictional dating world. The original Shorts experience remains available.

## What's inside

- **36 fictional adult female fly profiles**, each with three locally rendered portraits, three prompts, and a distinct personality.
- **One shared profile canvas** for the expanded app, the physical phone, and the fly's visual input.
- **Autonomous likes and passes** driven by a documented policy over measured PAM11 firing, with inspectable decision receipts.
- **Manual nudges:** like, pass, or send a rose. These are labeled operator overrides, not neural decisions.
- **A simulated social world:** incoming likes, mutual matches, authored conversations, date invitations, and date observations.
- **Local persistence and inspection:** paired brain/session checkpoints, archived sensory pixels, replay, JSON/CSV exports, and session comparison.

The brain runs locally in Python and C++; Three.js renders the chamber and profile portraits. Once the neural data is prepared, WING runs without cloud inference, real dating accounts, or downloaded videos. It is not affiliated with Hinge.

## Run it

You'll need **Python 3.11+**, a **C++17 compiler**, [uv](https://docs.astral.sh/uv/), and a browser with **WebGL 2**. Allow several GB of disk space; **16 GB RAM** is recommended. On macOS, install the compiler with `xcode-select --install` if needed.

From the root of this checkout:

```sh
uv sync --locked
uv run --locked flywirehead prepare
uv run --locked flywirehead run --dopamine-tonic 7 --run-dir runs/wing-active
```

Preparation downloads about **1.1 GB** of neural data and verifies its checksums. The native kernel builds on first use. No npm install or frontend build is required.

The last command opens [localhost:4173](http://127.0.0.1:4173/). Keep the Python process running. **Ctrl-C** saves the brain and dating session. Restart with the same command to restore them; restored sessions start **paused**, so click **Resume fly**. Use `--port 4174` if another server is already using the default port.

### Active dopamine mode

The quick start explicitly enables a **7 mV-equivalent tonic drive** to all 15 PAM11 dopamine neurons. This is a fixed, profile-independent experimental input that brings those cells into an active range. The displayed spikes are computed by the neural kernel, not generated by the chart.

**More activity does not automatically mean more likes.** Decisions still compare profile responses with a measured neutral baseline. This mode does not establish biological attraction or guarantee selective behavior.

### Unboosted control

To run without the tonic drive:

```sh
uv run --locked flywirehead run --run-dir runs/wing
```

Plain `flywirehead run` and the macOS `run.command` launcher select this **unboosted** mode, not the active-mode quick start above. PAM11 may remain at or near **0 Hz** even while the wider network is firing. Play resumes observations; it does not inject dopamine stimulation.

Use separate run directories when changing tonic current, the random seed, or the learning condition. WING refuses to restore a checkpoint with incompatible experiment settings, and `--fresh` does not overwrite an existing dating database. Use separate ports as well if running conditions simultaneously.

## What the fly actually receives

The browser captures the displayed phone canvas at **90×160 pixels**. Luminance and color drive **3,335 R1–R6 inputs and 811 R8 inputs** in the retained **MaleCNS v1.0** network. Accepted frames normally advance **50 ms of neural time**, using **0.1 ms integration steps**. Simulated time is not a claim of biological real-time playback.

The dating controller:

1. Measures reference variability on a neutral screen to set the session threshold.
2. Establishes a neutral baseline before each profile.
3. Collects a fixed amount of neural exposure for each of its three photos.
4. Computes the duration-weighted mean PAM11 firing rate above baseline.
5. Likes only when that delta exceeds the threshold and at least two photo windows rise above baseline; otherwise, records a pass with a reason.

Static photos are valid observations. Hidden tabs, paused sessions, unavailable rendering, and incomplete transitions supply no new frames; an observation already computing may finish. Missing media or a disconnected browser is not treated as a dislike. Foreleg taps and scrolls enact the controller's actions; they do not create the evidence used to choose them.

### What the numbers do not mean

**Real reconstructed wiring; approximate physiology; engineered behavior.** PAM11 activity is reported in spikes per neuron per simulated second (**Hz**), not dopamine concentration, an attraction percentage, or a measure of the entire network.

The model receives pixels. It does not understand names, English prompts, personality traits, or messages. A silent response is labeled **insufficient signal**, not evidence that the fly dislikes someone. The tested model can still pass on every profile; the app does not force a like ratio or invent fluctuations to make the experiment entertaining.

Profiles, reciprocal interest, and replies are fictional. **You write Francis's messages**; replies come from the seeded, authored social world, not language generated by the connectome. Attraction, pleasure, subjective experience, and useful learned preferences have not been established. No living fly is involved.

## Controls

| Input | Action |
| --- | --- |
| Pause / Resume fly, or **Space** | Pause or resume neural observations |
| **One profile** | Finish the current profile and stop after its action |
| Like / pass / rose buttons | Make a labeled operator decision |
| Drag the chamber | Orbit the camera |
| **Change view**, or **C** | Cycle camera positions |
| **Cinema** | Focus on the chamber |
| **Save experiment**, or **S** | Save the brain and dating session together |
| Discover / Standouts / Likes you / Messages / You | Browse the dating experience and spectator console |
| A decision in the journal | Inspect its receipt and replay recorded sensory pixels |
| Experiment settings | Export, compare an exported session, or record the chamber |

Keyboard shortcuts apply outside inputs and dialogs. Browsing the spectator console pauses neural observation. Reduced-motion preferences start the app paused and omit the action choreography. One browser window at a time owns the sensory stream.

## Persistence, replay, and experiments

Dating runs store structured state in `wing.sqlite3` and neural snapshots under `checkpoints/` inside their run directory. Decisions, social actions, explicit saves, and clean shutdowns commit paired state. Interrupted uncommitted work can be lost, but recovery restores a matching brain/session checkpoint rather than mixing different points in the experiment.

Decision receipts record the baseline, response, threshold, exposure, selected photo, experimental condition, and whether the action came from the neural policy or the operator. Archived inputs and measurements can be inspected in the app without changing the live brain.

To verify exact native replay of committed observations:

```sh
uv run --locked python scripts/replay_dating.py runs/wing-active
```

An optional **experimental learning mode** unfreezes plasticity:

```sh
uv run --locked flywirehead run --dopamine-tonic 7 --learning --run-dir runs/wing-learning-active
```

Only a committed neural like followed by a simulated mutual match triggers the post-decision training current. Outcome and washout observations are excluded from scoring. The default dating mode freezes plastic weights; enabling learning is not evidence that useful preferences have been learned.

### Visual-response assays

With a dating server running, render the exact retinal fixtures, then test the model separately:

```sh
uv sync --locked --extra test --extra browser
uv run --locked python scripts/render_profiles.py --count 36
uv run --locked python scripts/assay_dating.py --frames runs/profile-fixtures
uv run --locked python scripts/assay_policy.py
```

Fixture rendering requires an installed **Google Chrome** and produces 108 profile frames plus a neutral reference. The response assay repeats visual stimuli from reset neural state; the policy assay exercises the full frozen decision loop. These write results under `runs/` without advancing or replacing the live experiment. Results characterize the model, not biological attraction.

## Original Fly / Wirehead Shorts mode

The original experience is preserved with its own default run directory, `runs/local`. It additionally needs **yt-dlp**, **FFmpeg**, and browser **H.264 playback**. On macOS with Homebrew, install the video tools with `brew install yt-dlp ffmpeg`, then:

```sh
uv run --locked python scripts/download_videos.py
uv run --locked flywirehead run --experience shorts
```

Five insect Shorts loop with a new clip every three seconds of playback. This mode uses the original automatic **20 mV-equivalent PAM11 drive**, rather than WING's baseline-relative dating decisions. For an unstimulated Shorts control:

```sh
uv run --locked flywirehead run --experience shorts --no-video-reward --run-dir runs/shorts-control
```

Edit [video-sources.json](video-sources.json) to change the playlist; source links and creator credits are recorded in [the playlist](dist/media/playlist.json). See the inherited [Shorts model and operation notes](docs/model.md) and [validation history](docs/validation.md) for that experience. Their video-specific defaults and controls should not be confused with WING's dating mode.

## Check it

Fast Python and JavaScript checks:

```sh
uv sync --locked --extra test
uv run --locked pytest -q
node --test tests/*.test.mjs
```

After preparing the neural data, run the full-network and real-browser checks. Browser checks require Google Chrome and the optional browser dependencies:

```sh
uv sync --locked --extra test --extra browser
FLYWIREHEAD_FULL_TEST=1 FLYWIREHEAD_BROWSER_TEST=1 uv run --locked pytest -q
```

Tests cover neural responses, decision policies, observation ownership and deduplication, checkpoint recovery, gestures, the dating lifecycle, mobile layout, reduced motion, and stopping input after WebGL context loss. They test mechanisms and software behavior, not biological validity.
